This document outlines the architecture, tech stack, and step-by-step implementation phases for building the "Labour Link" web application.

## Proposed Tech Stack
*   **Architecture**: Decoupled Client-Server architecture.
*   **Frontend**: Next.js (App Router) located in the `/frontend` directory. Vanilla CSS for styling.
*   **Backend**: Node.js with Express located in the `/backend` directory.
*   **Database**: PostgreSQL with Prisma ORM for robust data modeling.
*   **Authentication**: Custom OTP-based authentication using JSON Web Tokens (JWT) for sessions.
*   **Real-time & Geolocation**: Socket.io for real-time gig tracking and location updates.
*   **Deployment**: Dockerized with `docker-compose.yml` for local development and a `render.yaml` blueprint for deployment on Render.

---

## Phase 1: Foundation & Restructuring
1.  Move the existing Next.js app into a `frontend` folder.
2.  Initialize a new Node.js/Express app in the `backend` folder.
3.  Create Dockerfiles for both `frontend` and `backend`.
4.  Create `docker-compose.yml` in the root for local development.
5.  Create `render.yaml` blueprint for easy deployment on Render.

## Phase 2: Authentication & Onboarding (Backend APIs & Frontend Integration)
1.  Database schema setup for Users (Home Owners, Shop Owners, Employees) via Prisma in the `backend`.
2.  Implement OTP Generation and Verification (Email & Phone) API routes.
3.  Build Login / Signup API routes and integrate with Frontend.

## Phase 3: Dashboards Implementation
### Shop Owner Dashboard
*   Responsive layout with Welcome header.
*   Overview cards: Earnings per day, Tasks completed per day.
*   Live earnings graph (using Chart.js or Recharts).
*   Employee Management: List of employees, add/edit employee details, performance stats.
*   Geospatial Map: Live location tracking of employees.
*   Gig Requests Section: Accept incoming requests and view accepted tasks.
*   Profile editing.

### Home Owner Dashboard
*   Discover section: Highly rated shops with photos and descriptions.
*   Search & Filter: Find workers by category (electricians, plumbers) and location.
*   Favorites functionality.
*   Shop details view and "Post a Gig" form (Date, Time, Address).

### Employee Dashboard
*   Simple interface to view assigned jobs.
*   Accept / Reject job requests.
*   Update live location (simulated or actual browser geolocation).

## Phase 4: Gig Lifecycle & Real-time Tracking
1.  **Gig Posting**: Home Owner posts gig -> Notification sent to Shop Owner.
2.  **Gig Acceptance**: Shop Owner accepts -> SMS/Email with tracking link sent to Home Owner.
3.  **Job Execution (OTP Flow)**:
    *   Start OTP generated by Home Owner and given to Employee upon arrival.
    *   Complete OTP generated by Home Owner when work finishes.
4.  **Live Tracking**: Home owner can view employee tracking details and verification on the tracking link page.

## Phase 5: Payment Integration
1.  Enable "Pay Now" button after the Complete OTP is verified.
2.  Integrate the chosen Payment Gateway for Cash, UPI, Cards, Net Banking.
3.  Handle payment success webhooks to update the gig status and Shop Owner's total earnings.

## Phase 6: Polish & SEO
1.  Implement SEO best practices.
2.  Refine UI/UX with smooth transitions and hover effects.
3.  Security review (input validation, rate limiting for OTPs, protected routes).
